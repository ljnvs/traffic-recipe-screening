# Data acquisition and representative panel format

The package redistributes aggregate scores and descriptors, not provider observations, processed panels or weights. Follow the providers' terms when obtaining data. Sources and fixed versions are those already specified in the manuscript:

* UTD19: https://utd19.ethz.ch/ ; see the dataset paper cited in the manuscript. Flow is vehicles/hour/lane and speed is km/h. The study retains each source's grid. Explicitly invalid targets are excluded; quality-unknown observations remain eligible under the declared primary protocol. Do not equate an unknown quality annotation with an observed zero.
* GO-MO: https://huggingface.co/datasets/dmariaa70/GO-MO/tree/1aa5f0dd4814c88607f5578d8e34ba27d70722cb ; fixed commit `1aa5f0dd4814c88607f5578d8e34ba27d70722cb`. Madrid uses original flow after the manuscript's interpolation/read-error flags, on the reported 15-minute grid. The representative period is 1–30 January 2015. Report native MAE in vehicles/hour/measurement point.
* Victoria 2014 traffic signal volume resource: https://opendata.transport.vic.gov.au/dataset/traffic-signal-volume-data/resource/fef12215-683b-4c5e-8210-5c152036a4d2 . The study uses 1–30 January 2014 from the resource under its earliest-month rule. Resource-file dates, rather than the catalogue's start-date label, define the panel. Node identity is a detector, the reporting grid is 15 minutes, and native values are vehicles/15 minutes/detector. Use rate factor four internally and restore native units before scoring. Ballarat and Greater Bendigo are source regions; Greater Geelong and Latrobe are targets. They share the provider and month.

Innsbruck uses 1–30 April 2017 and 15 retained nodes. The 15-minute derived grid averages three 5-minute hourly-rate observations, requiring all three to pass the quality rule. The package reports this stratum separately. Do not reinterpret its performance as an isolated causal effect of resampling. Its train/validation/test boundaries follow 8–17 April, 17–24 April and 24 April–1 May, respectively, as half-open intervals.

For the representative entry point, convert the chosen provider records to a strictly ordered 30-day array with exactly 96 reported slots/day and a fixed node order selected using the permitted prefix. Retain a deterministic mapping from provider node identity to the column index. Resolve duplicate/missing reported time keys before creating this array, documenting the decision. Do not silently relabel reported keys as certified UTC interval endpoints. Restrict node selection, fixed scaling and any task descriptors to the declared information prefix. Do not read validation/test performance to define those fields.

Write an NPZ with `raw`, `input_available`, `target_valid`. Input availability describes what could be used causally at its observation time; target validity describes eligibility for supervision and scoring. They are independent masks. The portable panel checks the shape and finite valid observations, constructs bounded causal input fill itself and leaves target values unfilled. The synthetic `demo` command is a format example; replacing it with real provider values requires provider-specific parsing and the manuscript's flags and node-selection rules. The package does not claim to supply a complete raw-provider downloader or parser.

The six earlier source-city tasks have different native cadences and prefix boundaries, listed in manuscript Appendix B. Their saved aggregate descriptors and labels are supplied for source-rule execution; they must not be fed to the fixed 15-minute representative panel without adapting its physical-time contract. External Graph WaveNet and STAEformer implementations and complete baseline preprocessing are obtained from their respective implementations referenced by the manuscript; they are not included in this package.
